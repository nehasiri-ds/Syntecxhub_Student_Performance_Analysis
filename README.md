# Student Performance Analysis

## Objective
Analyze student performance based on study hours and attendance.

## Tools Used
Python, Pandas, Matplotlib, Seaborn

## Dataset
The dataset contains student marks, attendance, and study hours.

## Analysis
- Data cleaning
- Performance analysis
- Visualization

## Insights
1. Students who study more score higher.
2. Higher attendance leads to better performance.
3. Math is slightly difficult compared to other subjects.
4. Low study hours lead to poor performance.

## Recommendations
1. Maintain attendance above 85%.
2. Study at least 5–6 hours daily.
3. Focus more on weak subjects.
4. Provide support to low-performing students.
